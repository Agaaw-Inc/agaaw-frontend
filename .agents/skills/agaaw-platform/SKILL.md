# Core User Types:
- Student
- Mentor (Consultant)

# Primary Features:
- Scholarships
- Countries
- Mentorship
- Application Tracking
- Resources & Blogs
- Document Management

# Rules:
- Always preserve role-based access.
- Student-only features must not be visible to mentors.
- Mentor-only features must not be visible to students.
- Dashboard must be personalized.

# UI Style:
- Modern SaaS
- Clean spacing
- Mobile-first
- Professional but student friendly
- Stripe Dashboard, Linear, Notion, Airbnb Host Dashboard

# Design instructions
When designing, follow these steps:
- clean, modern, trustworthy, premium inspired by: Upwork, Fiveer
- Avoid generic educational website styling
- Use Rounded corners (16px–24px), Soft shadows, Modern card layouts, Professional typography, Elegant gradients, Responsive design, Smooth hover effects
